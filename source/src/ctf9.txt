tx: Debugging strategy (written for this lesson): ¶ 1. Reproduce: Make the bug happen again on purpose. Write down exactly what you did. ¶ 2. Isolate: Find the smallest part of the code where it goes wrong. Turn blocks off or add a "say" block to show a variable's value. ¶ 3. Trace: Follow the code step by step. What did you expect? What actually happened? ¶ 4. Fix one thing: Change one thing, then test again. ¶ 5. Check edge cases: empty list, a date in the past, a very long task name, pressing a button twice. ¶ Sample bugs to fix: ¶ Bug A: The task counter shows 0 even when there are tasks. (The counter is reset to 0 inside the loop instead of before it.) ¶ Bug B: Every task shows in red. (The condition checks "due date ≥ tomorrow" instead of "due date = tomorrow.") ¶ Bug C: The app crashes when the list is empty. (The code reads item 1 without checking the list has items.) ¶ For videos: check audio levels, spelling in titles, jump cuts and length.
