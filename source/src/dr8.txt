v: line call :: When an actor asks the prompter for a forgotten line by saying "Line."
ts: Running the Show || Performance || How does a stage manager help a scene come together?
tx: Stage manager duties (written for this lesson): Before rehearsal: set up the space, preset props, check costumes. During rehearsal: follow the script, prompt lines, record blocking changes in the prompt book, time the scene. Before performance: call "Places, please," check everyone is ready. During performance: call cues ("Lights up, go"; "Music, go"), watch for problems. After: return props, write a rehearsal report. ¶ Task: In groups of three, one person is the stage manager and two are actors. ¶ 1. SM sets up a prompt book: a copy of the script with blocking, props and two cues marked (lights up at the start, lights down at the end). ¶ 2. Rehearsal (15 minutes): SM runs the scene, prompts any "Line" call, notes changes. ¶ 3. Dress rehearsal (10 minutes): Full run with costumes, props and cues. SM calls places and cues. ¶ 4. Performance (10 minutes): Perform for the class. ¶ 5. SM writes a short rehearsal report: time, problems, notes for next time.
